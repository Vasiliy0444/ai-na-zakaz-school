# ИИ на заказ — сайт проекта

Статический информационный сайт проекта онлайн-курса. Исходная рабочая программа хранится в локальном проекте `research/10-programma-kursa/programma-kursa.md`.

Публикация: GitHub Pages из ветки `main`, корень репозитория. На сайте не собираются данные и не принимается оплата. До запуска продаж требуется указать подтверждённые цену, условия доступа, контакт для покупателей и ссылку на оферту.
